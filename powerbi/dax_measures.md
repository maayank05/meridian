# DAX measures (canonical KPIs)

Each measure mirrors the SQL definition in `backend/sql/migrations/0004_kpi_views.sql`. Put them in a `_Measures` table. Format money as currency (BRL, 2 decimals) and rates as percentages. All measures are **derived** (provenance).

```dax
-- K01 Delivered Merchandise Value (Revenue Proxy): item price of DELIVERED orders by purchase date (D-016).
-- Not accounting revenue, not profit; freight excluded.
Delivered Merchandise Value (Revenue Proxy) =
CALCULATE ( SUM ( fact_order_items[price] ), fact_orders[order_status] = "delivered" )

-- K02 Freight billed on delivered orders
Freight Billed =
CALCULATE ( SUM ( fact_order_items[freight_value] ), fact_orders[order_status] = "delivered" )

-- K03 Delivered orders
Delivered Orders =
CALCULATE ( COUNTROWS ( fact_orders ), fact_orders[order_status] = "delivered" )

-- K04 Average order value = K01 / K03 (blank when no delivered orders)
Average Order Value =
DIVIDE ( [Delivered Merchandise Value (Revenue Proxy)], [Delivered Orders] )

-- K06 Orders placed (any status)
Orders Placed =
COUNTROWS ( fact_orders )

-- K12 Cancellation rate: status 'canceled' only (RULE-26)
Cancellation Rate =
DIVIDE ( CALCULATE ( COUNTROWS ( fact_orders ), fact_orders[order_status] = "canceled" ), [Orders Placed] )

-- K26 Unavailable order rate, reported separately (RULE-26)
Unavailable Order Rate =
DIVIDE ( CALCULATE ( COUNTROWS ( fact_orders ), fact_orders[order_status] = "unavailable" ), [Orders Placed] )

-- K21 Active customers: distinct people with a delivered order (RULE-02)
Active Customers =
CALCULATE (
    DISTINCTCOUNT ( dim_customer[customer_unique_id] ),
    fact_orders[order_status] = "delivered",
    CROSSFILTER ( fact_orders[customer_id], dim_customer[customer_id], BOTH )
)

-- K15 On-time delivery rate: delivered orders with a delivery date, delivered on/before the estimate (RULE-11/12)
On-Time Delivery Rate =
VAR eligible =
    FILTER ( fact_orders,
        fact_orders[order_status] = "delivered" && NOT ISBLANK ( fact_orders[delivered_customer_local] ) )
RETURN
    DIVIDE (
        COUNTROWS ( FILTER ( eligible,
            INT ( fact_orders[delivered_customer_local] ) <= INT ( fact_orders[estimated_delivery_date] ) ) ),
        COUNTROWS ( eligible )
    )

-- K13 Average review score: mean over orders of each order's mean score (D-019b)
Average Review Score =
AVERAGEX ( VALUES ( fact_reviews[order_id] ), CALCULATE ( AVERAGE ( fact_reviews[review_score] ) ) )

-- K19 Payment value (use with fact_payments[payment_type] for the mix)
Payment Value =
SUM ( fact_payments[payment_value] )
```
